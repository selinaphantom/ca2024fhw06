#  Unity 3D VTuber 動畫製作專案

本專案致力於使用 Unity 打造一個完整的 3D 動畫流程，透過匯入自製 VTuber 角色（VRM 格式）、結合由動作捕捉器生成的 FBX 動作檔，搭配音樂與運鏡剪輯，實現人物跳舞的完整動畫演出。

## 🛠 技術架構

- **Unity**：搭建 3D 場景與動畫製作核心引擎。
- **VRM 模型**：使用自製 VTuber 人物，支援表情與骨架綁定。
- **FBX 動作檔**：從動作捕捉器（如 Rokoko、Perception Neuron 等）獲取跳舞動作數據。
- **音樂剪輯**：配合角色動作剪接背景音樂，強化整體節奏感。
- **運鏡剪輯**：使用 Unity Timeline 與 Cinemachine 調度鏡頭運動，增強畫面表現力。

##  使用套件

- [UniVRM](https://github.com/vrm-c/UniVRM)
- [Cinemachine](https://docs.unity3d.com/Packages/com.unity.cinemachine)
- [Unity Recorder](https://docs.unity3d.com/Packages/com.unity.recorder)
